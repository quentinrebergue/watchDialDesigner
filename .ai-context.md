## Architecture Patterns

### Data Flow

```
React Components  ──(read)──>  Zustand Store  <──(write)──  Engine Callbacks
       │                            │
       └──(useEffect sync)──>  CanvasEngine  ──(Paper.js)──>  <canvas>
```

1. **UI → Store**: components call store actions directly (e.g., `setActiveTool`)
2. **Store → Engine**: `Sketch.tsx` watches store slices via `useEffect` and calls engine setters
3. **Engine → Store**: engine fires callbacks (`onSelectionChange`, `onPushUndo`, `onZoomChange`, `onToolChange`) that write back to store
4. **Components → Engine**: some components call `getEngine()?.methodName()` for imperative actions (e.g., toolbar buttons)

### Engine Module Communication

All engine sub-modules share an `EngineContext` object:

```typescript
interface EngineContext {
  scope: paper.PaperScope;
  canvas: HTMLCanvasElement;
  gridLayer: paper.Layer;
  dialLayer: paper.Layer;
  drawLayer: paper.Layer;
  overlayLayer: paper.Layer;
  callbacks: EngineCallbacks;
}
```

Sub-modules never import each other. The orchestrator (`CanvasEngine`) coordinates between them.

### Coordinate System

- Origin `(0,0)` = center of dial
- `MM_TO_PX = 10` — multiply mm values by 10 to get Paper.js points
- All UI inputs are in **millimeters**; conversion happens at the engine boundary
- Rotation stored in `item.data.rotation` (degrees), applied via `item.rotate(delta, center)`

### Undo/Redo

- JSON snapshot approach: `paper.project.exportJSON()` / `importJSON()`
- Snapshots pushed before each mutation via `onPushUndo` callback
- Stack capped at 50 entries
- `restoreFromJSON()` replaces the entire `drawLayer` contents

## Key Types

```typescript
// 11 available tools
type Tool = 'select' | 'line' | 'polyline' | 'arc' | 'circle' |
            'ellipse' | 'rectangle' | 'polygon' | 'dot' | 'text' | 'pan';

// Selection properties sent from engine → store → UI
interface SelectionPropsPayload {
  x: number; y: number;           // center position in mm
  width: number; height: number;  // bounding box in mm
  rotation: number;               // degrees
  isText: boolean;
  textContent: string;
  strokeColor: string;
  fillColor: string;
  strokeWidth: number;            // in mm
  textAlignH: 'left' | 'center' | 'right';
  textAlignV: 'top' | 'center' | 'bottom';
}

// Drawing style passed to DrawingTools
interface DrawStyle {
  strokeColor: string;
  fillColor: string;
  strokeWidth: number;       // in mm (already converted to px in store)
  polygonSides: number;
}

// Grid configuration
interface GridSettings {
  showPolar: boolean;
  showCartesian: boolean;
  polarCircleSpacing: number;   // mm
  polarAngleSpacing: number;    // degrees
  cartesianSpacing: number;     // mm
  snapSpacing: number;          // mm
}

// Snap configuration
interface SnapSettings {
  enabled: boolean;
  grid: boolean;
  points: boolean;
  angular: boolean;
  angularStep: number;          // degrees
}
```

## Common Modification Patterns

### Adding a New Drawing Tool

1. Add tool name to `Tool` union in `store.ts`
2. Add tool entry in `Toolbar.tsx` tools array (icon, label, shortcut)
3. Add keyboard shortcut case in `Sketch.tsx` keydown handler
4. Implement `showXPreview()` + `commitX()` in `DrawingTools.ts`
5. Add mouse event routing in `CanvasEngine.ts` (`handleDrawDown`, `handleDrawDrag`, `handleDrawUp`)
6. Add to `drawingTools` set in `ToolStylePanel.tsx` if it uses stroke/fill

### Adding a Selection Property

1. Add field to `SelectionPropsPayload` in `engine/types.ts`
2. Populate it in `SelectionManager.updateSelectionHighlight()`
3. Add setter method in `SelectionManager`
4. Add public wrapper in `CanvasEngine`
5. Add UI control in `SelectionPanel.tsx`

### Adding a Store Field

1. Add to `AppState` interface in `store.ts`
2. Add default value + setter in the `create()` call
3. Subscribe in `Sketch.tsx` useEffect + call engine setter

### Adding a Panel Sub-Component

1. Create `panels/XPanel.tsx` using `<Panel>` and `<Field>` from `Panel.tsx`
2. Add to `PropertiesPanel.tsx` imports and JSX
3. Export from `panels/index.ts`

## Conventions

- **No CSS modules or styled-components** — Tailwind utility classes only
- **No prop drilling** — components read from Zustand directly via `useAppStore`
- **Engine is React-free** — never import React or store in `engine/` files
- **Imperative engine access** — via `getEngine()` exported from `Sketch.tsx`
- **Units in UI** — always millimeters; conversion at engine boundary
- **Formatting** — Prettier with defaults (single quotes disabled — uses double quotes)
- **Linting** — ESLint v9 flat config; `eslint-config-prettier` disables conflicting rules
